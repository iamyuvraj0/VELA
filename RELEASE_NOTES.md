# VELA v1.0.3

## Highlights

- Added Spotify playlist import from **Settings > Backup & Restore**.
- Paste a public Spotify playlist link and import tracks into a VELA playlist.
- Choose an existing playlist or create a new playlist during import.
- Tracks are matched through YouTube Music before being added to VELA.
- Release APK filename is exactly `VELA.apk`.

- Package: `com.iamyuvraj0.vela`
